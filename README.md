## Installation on a web hotel
Get free API keys from:

### * TomTom

### * AISStream

### * Trafiklab GTFS Sweden 3 Realtime

### * Trafikverket

### * Windy

### * Västtrafik "Planera Resa v4"


Put you own API keys in config.php and upload to a webserver. PHP needs cURL and GD
